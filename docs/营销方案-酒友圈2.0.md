# 酒友圈 2.0 营销方案

> 版本：v1.0
> 日期：2026-05-09
> 状态：初稿

---

## 一、市场机会

### 1.1 为什么现在做

- **贵州酒商数字化程度低**：大量小酒商靠朋友圈、口口相传，没有数字化营销工具
- **消费者喝酒记录需求**：喝完就忘，无法量化自己的饮酒行为
- **积分兑换模式成熟**：航空、银行、电商平台已验证，迁移到酒类赛道可行
- **监管空白期**：酒友圈定位为「营销工具」而非「社交平台」，监管压力小

### 1.2 目标市场

- **地域**：贵州为主，辐射西南
- **B端**：贵州本地小酒厂、酒坊、散酒店
- **C端**：25-45岁男性，有饮酒习惯，注重性价比

## 二、差异化定位

### 2.1 我们是什么

> **「喝多少，攒多少，换多少」**
> 喝酒也能当钱花 —— 每一口酒都是积分，积分可换实物。

### 2.2 核心价值主张

| 角色 | 核心诉求 | 我们给什么 |
|------|----------|------------|
| 喝酒用户 | 喝酒有意义、得到实惠 | 积分换商品，实打实的好处 |
| 小酒商 | 获客、复购、品牌曝光 | 低成本数字化营销工具 |

### 2.3 差异化关键词

- **AI识别**：拍照就知道是什么酒、市场价多少——最懒的记录方式，也是核心传播噱头
- **贵州特色**：家乡特产兑换，突出本地化
- **积分不浪费**：喝酒积分，兑换实物，而非虚拟道具

## 三、核心增长策略

### 3.1 用户增长飞轮

```
喝酒记录 ──▶ 获得积分 ──▶ 积分换商品 ──▶ 觉得划算
    ▲                                      │
    │                                      ▼
    └──────────── 分享裂变 ◀────── 邀请好友
```

**核心逻辑**：越喝越换，越换越喝，越分享越赚

### 3.2 第一阶段（0→500用户）：冷启动

**策略**：搞定第一批「爱喝酒、爱分享」的用户

**动作**：
1. **定向邀请**：找10个爱喝酒的KOC，赠送500积分体验兑换
2. **线下渗透**：在贵阳、遵义酒吧/餐饮聚集地地推，扫码送50积分
3. **朋友圈传播**：首批用户分享喝酒记录到朋友圈，集赞送积分
4. **AI功能引爆**：AI识别酒名作为传播噱头（"拍一下就知道这酒值多少"）

**目标**：500真实用户，人均记录≥3次

### 3.3 第二阶段（500→5000用户）：商户+裂变

**策略**：酒商带用户，用户带用户

**动作**：
1. **酒商驱动**：入驻10家小酒商 → 每家自带50-100用户
2. **分享裂变**：分享喝酒记录得积分，被邀请人注册得积分，双方得利
3. **新客券**：入驻酒商发放「新客专享券」吸引首单
4. **贵州特产专区**：上线贵州本地特产作为积分兑换商品，制造话题

**目标**：5000用户，月活2000+

### 3.4 第三阶段（5000+用户）：内容+广告

**策略**：建立内容生态，广告位变现

**动作**：
1. **话题活动**：#今晚喝什么、#贵州人喝贵州酒 等话题
2. **酒商PK**：月度酒商销量排行，排行榜曝光
3. **广告位上线**：商户购买banner位、推荐位
4. **CPT/CPM售卖**：首页banner、领券中心等广告位开放

## 四、商户（B端）营销策略

### 4.1 招募策略

**目标**：先招5-10家小酒商，打样验证

**招募渠道**：
- 贵州本地酒类微信群、QQ群
- 贵阳糖酒会等线下活动
- 58同城/赶集网筛选酒类商家电话
- 地推：仁怀、遵义酒厂集中区域

**招募话术**：
> 「免费入驻，帮你发券获客，不效果不收钱」

**入驻激励**：
- 前3个月免入驻费
- 平台补贴首期广告费（每家500元广告金）
- 1V1运营支持

### 4.2 酒商赋能

| 赋能 | 说明 |
|------|------|
| 发券工具 | 3分钟创建优惠券，无需技术 |
| 数据面板 | 看得到自己的用户和订单 |
| AI识别曝光 | 用户AI识别酒名时，优先推荐合作品牌 |
| 平台背书 | 「精选酒商」标识，提升信任 |

### 4.3 酒商合作案例模板

```
案例：「XX酒坊」入驻酒友圈
- 背景：仁怀一家小型酱酒作坊，无线上营销能力
- 动作：发放500张「满200减30」新客券
- 结果：1个月新增客户120人，复购率35%
- 成本：优惠券核销2400元（平台补贴部分）
```

## 五、C端用户营销策略

### 5.1 首单转化

**策略**：让用户第一笔积分兑换「超预期」

**动作**：
- 新用户注册送200积分（相当于2元）
- 首单兑换+额外奖励积分（如+50）
- 前100名兑换用户免运费

**话术**：
> 「注册就送积分，喝酒不要钱」

### 5.2 留存策略

| 策略 | 动作 |
|------|------|
| 签到 | 每日签到+5积分，连续7天额外+20 |
| 提醒 | 「你的积分即将过期」推送 |
| 目标感 | 显示「再喝X元，够换XX商品」 |
| 进度条 | 个人中心显示积分进度（如：差3000积分换AirPods） |

### 5.3 裂变策略

| 方式 | 规则 | 奖励 |
|------|------|------|
| 邀请注册 | 分享链接给好友 | 邀请人+100积分，好友+50积分 |
| 分享记录 | 分享喝酒记录到微信 | 每次+3积分，每日限3次 |
| 集赞 | 朋友圈集赞满20个 | 截图上传得+50积分 |

## 六、商品与积分策略

### 6.1 积分价值锚定

**原则**：让用户觉得积分值钱

- **定价参考**：100积分 = 1元人民币
- **兑换价**：市场价 × 70%（平台补贴30%）
- **补差价**：用户可用「积分+现金」混合支付

### 6.2 引流商品（低积分高吸引力）

| 商品 | 积分要求 | 市场价 | 吸引点 |
|------|----------|--------|--------|
| 可乐/雪碧 | 100积分 | 3元 | 门槛低，快速首兑 |
| 抽纸 | 500积分 | 10元 | 刚需品 |
| 黔五福礼盒 | 2000积分 | 40元 | 贵州特色 |
| 500ml白酒（口粮酒）| 5000积分 | 100元 | 酒换酒，闭环 |

### 6.3 高价值商品（拉升ARPU）

| 商品 | 积分要求 | 市场价 | 目标用户 |
|------|----------|--------|----------|
| 小米充电宝 | 10000积分 | 80元 | 3C用户 |
| 筋膜枪 | 20000积分 | 200元 | 运动人群 |
| AirPods | 50000积分 | 900元 | 高价值用户 |

### 6.4 贵州特产专区

**定位**：只有在我们平台才能用积分换到的贵州特色商品

- 茅台系列周边（限积分兑换）
- 贵州腊肉/辣椒/酸汤等特产
- 少数民族手工艺品
- 目的：制造「稀缺感」，提升平台差异化
