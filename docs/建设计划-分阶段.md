# 酒友圈 2.0 建设计划（分阶段）

> 版本：v1.0
> 日期：2026-05-09
> 状态：初稿

---

## 总体原则

- 每个阶段交付可用的最小功能集
- 验证核心假设后再进入下一阶段
- 不做过度设计

---

## Phase 0：现有稳定（1周）

**目标**：酒友圈1.0稳定运行，作为基础

### 现有能力
- ✅ 登录注册
- ✅ 喝酒记录（拍照+定位）
- ✅ 排行榜
- ✅ 个人主页
- ✅ 关注/取关

### 需修复问题
- 定位API失效（腾讯地图key缺失）
- 界面UI优化
- 已发现bug修复

### 交付物
- 酒友圈1.0稳定版在服务器运行

---

## Phase 1：积分体系 MVP（4-6周）

**目标**：验证"喝酒得积分，积分换商品"核心逻辑

### C端开发

| 功能 | 优先级 | 说明 |
|------|--------|------|
| AI拍照识别酒名 | P0 | 拍酒瓶→AI识别酒名+品牌+市场价 |
| 扫码识别酒名 | P1 | 扫条码→返回酒名+参考价 |
| 喝酒记录页改版 | P0 | 集成AI识别结果展示+确认 |
| 积分账户页 | P0 | 显示总积分 + 明细列表 |
| 积分商城首页 | P0 | 商品列表 + 分类筛选 |
| 商品详情页 | P0 | 积分兑换按钮 |
| 订单确认页 | P0 | 选择地址 + 确认兑换 |
| 订单列表页 | P0 | 订单状态跟踪 |
| 我的卡包 | P1 | 已领优惠券列表 |

### 后端开发

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 积分账户表/接口 | P0 | points_account |
| 积分明细表/接口 | P0 | points_log |
| 积分发放逻辑 | P0 | 喝酒记录触发放积分 |
| 商品表/接口 | P0 | products |
| 订单表/接口 | P0 | orders |
| 地址表/接口 | P1 | user_addresses |

### 数据准备
- 手动录入 20-30 个商品（标准品类）
- 定价：对标淘宝/拼多多最低价 × 70%
- 商品图片：爬取或手动上传

### 验收标准
- [ ] 用户完成喝酒记录，能看到积分增加
- [ ] 用户能用积分兑换商品
- [ ] 订单能生成并查看状态
- [ ] 100个真实用户体验完整流程

---

## Phase 2：商户入驻 + 优惠券（4-6周）

**目标**：B端商户入驻平台，发券工具上线

### C端新增

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 领券中心 | P0 | 领券列表 |
| 领券详情 | P0 | 券详情 + 使用说明 |
| 商户店铺页 | P1 | 查看商户店铺 |

### B端（商户后台）

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 商户注册/登录 | P0 | 手机号 + 资质上传 |
| 入驻审核 | P0 | 平台审核商户资质 |
| 店铺信息管理 | P0 | 商户名称/头像/简介 |
| 发券工具 | P0 | 创建满减/折扣/秒杀券 |
| 券管理 | P0 | 查看发出去的券 |
| 核销功能 | P0 | 扫码核销 |
| 订单管理 | P1 | 查看核销订单 |

### 平台运营后台

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 商户审核 | P0 | 审核入驻申请 |
| 商户列表 | P0 | 管理商户状态 |
| 券审核 | P0 | 审核商户创建的券 |

### 验收标准
- [ ] 5-10家小酒商入驻并发布优惠券
- [ ] C端用户能领取优惠券
- [ ] 商户能核销优惠券
- [ ] 优惠券核销率 > 20%

---

## Phase 3：价格对标系统（4-6周）

**目标**：自动化商品价格对标，降低运营成本

### 技术开发

| 功能 | 优先级 | 说明 |
|------|--------|------|
| 价格抓取脚本 | P0 | 定时抓取主流电商最低价 |
| 价格更新接口 | P0 | 自动更新商品兑换价 |
| 贵州特产专区 | P1 | 突出贵州酒/特产的积分兑换 |
| 批量商品导入 | P1 | CSV导入商品数据 |

### 商品扩展
- 接入淘宝联盟 / 拼多多联盟 API（若有）
- 或者自建爬虫抓取
- 商品品类扩展到100+

### 验收标准
- [ ] 每日自动更新商品价格
- [ ] 价格对标误差 < 5%
- [ ] 商品数量 > 100 个
