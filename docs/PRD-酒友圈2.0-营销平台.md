## 一、项目概述

### 1.1 产品定位

**酒友圈2.0** —— 贵州小酒商营销平台 + 消费者积分权益平台

核心逻辑：**喝酒记录 → 积分累积 → 兑换商品**

- **B端**：贵州小酒商入驻，发优惠券、秒杀活动，获取客户、复购
- **C端**：用户记录喝酒、攒积分、领优惠券、换商品
- **平台**：对接商品价格数据，抽佣/广告/营销工具变现

### 1.2 解决问题

| 角色 | 痛点 | 解决方案 |
|------|------|----------|
| 小酒商 | 没有数字化能力，只能靠线下口口相传 | 入驻平台，数字化营销工具 |
| 消费者 | 喝酒花费无法留存，白喝 | 积分换商品，花喝酒的钱得实物 |
| 平台 | 酒友圈1.0无变现路径 | B端入驻费 + 抽佣 + 营销工具 |

## 三、详细功能说明

### 3.1 C端功能

#### 3.1.1 登录注册
- 手机号 + 验证码登录（已有）
- 微信一键登录（后续）
- 完善个人信息（头像/昵称/地区）

#### 3.1.2 喝酒记录（AI 智能录入）
- **拍照识别**（P0）：拍一张酒瓶/酒杯照片 → AI自动识别酒名、品牌、类型
- **扫码识别**（P1）：扫商品条码 → 返回酒名+参考市场价
- **识别结果展示**：识别出酒名后，显示「市场参考价」，用户确认/修改金额
- **价格参考**：基于 AI 识别 + 价格数据库，自动填充建议金额
- **手动补充**：用户可修改酒名、类型、金额
- **定位**：GPS定位 + 逆地址解析
- **拍照**：拍照上传，自动压缩（识别用）
- **积分数**：根据金额自动计算（规则：1元=1积分）
- 提交后积分即时到账

#### 3.1.3 积分账户
- 总积分展示
- 积分来源明细（喝酒获得/兑换消耗/退款返还）
- 积分到期提醒（可选）

#### 3.1.4 积分商城
- 商品列表（对标市场最低价）
- 商品分类（食品/日用品/数码/家乡特产等）
- 积分 + 现金混合兑换（部分积分+补差价）
- 订单状态跟踪

#### 3.1.5 领券中心
- 可领取优惠券列表
- 券的类型：满100减20 / 秒杀 / 新客券
- 领券后在我的卡包查看
- 券的使用说明

#### 3.1.6 订单管理
- 积分兑换订单
- 现金购买订单（后续）
- 退款售后

### 3.2 B端功能

#### 3.2.1 入驻
- 提交资质（营业执照/食品流通许可）
- 填写店铺信息
- 审核状态跟踪

#### 3.2.2 发券工具
- **满减券**：满X元减Y元
- **折扣券**：X折
- **新人券**：限新用户领取
- **秒杀**：限时特价
- 设定发放数量/有效期

#### 3.2.3 核销管理
- 扫码核销（用户出示券码）
- 核销记录查询
- 退款处理

#### 3.2.4 数据面板
- 今日/本周/本月订单
- 券领取/使用率
- 用户地域分布

### 3.3 平台运营功能

#### 3.3.1 商户管理
- 入驻审核
- 资质管理
- 违规处理

#### 3.3.2 商品管理
- 商品录入/编辑
- 价格对标配置
- 库存管理
- 商品上下架

#### 3.3.3 广告位管理
- **广告位类型**：首页banner / 积分商城轮播 / 领券中心推荐位
- **广告主**：平台自营商品 / 商户付费推广 / 外部广告
- **售卖方式**：CPT（按时长）/ CPM（按曝光）/ CPC（按点击）
- **排期管理**：设定广告展示时间段
- **数据统计**：曝光量/点击量/转化率

### 3.3.4 价格对标系统
- 对接淘宝/拼多多/京东商品API（或者爬虫）
- 自动抓取同款最低价
- 平台补贴差额定价
- 价格更新频率：每日

## 四、积分体系

### 4.1 积分规则

| 行为 | 积分 | 说明 |
|------|------|------|
| 喝酒记录（金额 X 元） | X 积分 | 1:1 获取 |
| 每日签到 | +5 积分 | 连续7天额外+20 |
| 完成新手引导 | +50 积分 | 仅一次 |
| 分享喝酒记录 | +3 积分 | 每日限3次 |
| 兑换商品（消耗） | -N 积分 | 按商品定价扣除 |
| 退款（商品退货） | +N 积分 | 积分返还 |

### 4.2 积分价值锚定

- **参考值**：100积分 ≈ 1元人民币
- **商品定价**：市场价 × 70% ≈ 积分兑换价（平台补贴30%）
- 补贴来源：商户入驻费 / 广告费 / 抽佣

### 4.3 积分到账规则

- 喝酒记录审核通过后即时到账
- 积分不可转让
- 积分有效期：获得后12个月，过期清零（可续）

## 五、商品体系

### 5.1 商品来源

| 品类 | 来源 | 说明 |
|------|------|------|
| 家乡特产（贵州） | 平台自营或商户供货 | 差异化竞争 |
| 食品日化 | 对接电商API / 供应链 | 标准化商品 |
| 数码配件 | 对接供应链 | 高积分需求商品 |
| 话费/油卡 | 官方合作 | 刚需商品 |

### 5.2 价格对标逻辑

```
商品兑换价 = 市场最低价 × 70%
用户实际支付积分 = 兑换价（元）× 100

举例：
- 某商品市场价100元，最低88元
- 平台兑换价 = 88 × 70% = 61.6元
- 用户需支付 = 6160积分 + 可选补差价
```

### 5.3 商品展示字段

- 商品名称

- 品牌/规格
- 市场价格
- 平台兑换积分
- 剩余库存
- 快递信息

## 六、优惠券体系

### 6.1 券类型

| 类型 | 说明 | 示例 |
|------|------|------|
| 满减券 | 消费满X减Y | 满100减20 |
| 折扣券 | 打X折 | 8折 |
| 无门槛券 | 无门槛使用 | 减5元 |
| 新客券 | 仅新用户领取 | 首单减10 |
| 秒杀券 | 限时限量特价 | 限量100张 |

### 6.2 券的流转

1. **商户创建** → 设置类型/数量/有效期
2. **平台审核** → 确认后上线
3. **用户领取** → 领取后存入我的卡包
4. **下单使用** → 选券抵扣
5. **核销** → 商户扫码确认

### 6.3 券的成本

- 满减/折扣：由商户承担
- 新客引流券：平台补贴（吸引用户）
- 秒杀：商户出商品，平台补贴营销费

## 七、运营方案

### 7.1 冷启动策略（Phase 1）

- 招募 5-10 家贵州小酒商免费入驻
- 用户目标：先累积 500-1000 真实用户
- 核心诱因：喝酒得积分，积分换商品
- 验证：积分兑换核销率 > 30%

### 7.2 增长策略（Phase 2）

- 分销裂变：分享喝酒记录得积分
- 酒商推广：酒商自推广拉新
- 积分活动：节日双倍积分

### 变现路径

| 阶段 | 变现方式 |
|------|----------|
| Phase 1 | 商户入驻费（免费试运营） |
| Phase 2 | 商户入驻费 + 抽佣 5-10% |
| Phase 3 | 广告费 + 营销工具付费 + 供应链差价 |
| Phase 4 | 广告位竞价 + 竞价排名 + 数据服务 |

## 十、风险与对策

| 风险 | 级别 | 对策 |
|------|------|------|
| 酒类内容监管 | 高 | 去社交化，定位工具属性 |
| 积分价值泡沫 | 中 | 控制积分发放量，设置上限 |

| 市场竞争 | 低 | 专注贵州小酒商细分市场 |

## 十一、附录

### 11.1 名词解释

- **积分**：用户在平台的虚拟资产，通过喝酒获取
- **兑换价**：商品用积分兑换的价格（低于市场价）
- **核销**：商户确认优惠券已被使用
- **对标**：抓取主流电商同款商品最低价
